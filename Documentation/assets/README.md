# PortalAI README artwork

The branding and interface images in this folder come from the existing PortalAI Academic Windows payload. They are used by the repository landing page.

| Asset | Origin |
| --- | --- |
| `portalai-logo.png` | Unmodified `Art Assets/Emblems/PortalAI_Emblem_HeroClean_320.png`. |
| `portalai-wordmark.png` | Unmodified `Art Assets/Wordmarks/PortalAI_Wordmark_Welcome.png`. |
| `welcome-panel.jpg` | The original `ControlCenter/public_welcome.py` welcome panel, using the application's dark palette and branding. |
| `chat-model-settings.jpg` | The original Academic `ControlCenter/settings_page.py` chat model and memory panel. |
| `media-defaults.jpg` | The original Academic `ControlCenter/settings_page.py` media defaults panel. |

The screenshots were captured from isolated preview windows on October 20, 2026. The settings panels use an in-memory sample inventory, with models marked as not installed. No personal profiles, chat history or credentials were loaded, and no model workers or application installation were started. The active PortalAI installation was not modified.

These are screenshots of real widgets, not generated interface mockups. The original screenshots and transparent branding images are preserved without visual edits. Platform styling and available components may differ on recipient systems.
