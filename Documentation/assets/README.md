# PortalAI README artwork

The branding and interface images in this folder come from the existing PortalAI Academic Windows payload. They are used by the repository landing page.

| Asset | Origin |
| --- | --- |
| `portalai-logo.png` | Unmodified `Art Assets/Emblems/PortalAI_Emblem_HeroClean_320.png`. |

| `welcome-panel.jpg` | The signed-in welcome page constructed by `ControlCenter/PortableAI_GUI.py`, with its original custom title bar, navigation, decorative borders and responsive welcome emblem. |
| `chat-panel.jpg` | The original `ControlCenter/native_chat.py` Chat panel inside the complete Control Center window, with an illustrative classroom conversation. |

| `media-defaults.jpg` | The original Academic `ControlCenter/settings_page.py` media defaults panel inside the complete Control Center window. |

The screenshots were captured on October 20, 2026 from an isolated copy of the Academic payload. A capture harness runs the original full Control Center UI construction while replacing account access, runtime processes, background jobs and network services with inert preview substitutes. It preserves the application's widget construction, custom title bar, borders, navigation and compact-mode implementation. The welcome capture shows the complete emblem at a window size that accommodates it.

The settings panels use an in-memory sample inventory, with models marked as not installed. The chat text is an illustrative classroom example supplied for the screenshot; it was not generated by a running model. No personal profiles, chat history or credentials were loaded, and no model workers or application installation were started. The active PortalAI installation and the published installer packages were not modified.

These are screenshots of real widgets, not generated interface mockups. The original screenshots and transparent branding images are preserved without visual edits. Platform styling and available components may differ on recipient systems.
