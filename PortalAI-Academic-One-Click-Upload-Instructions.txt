STUDENT DOWNLOADS
- PortalAI-Academic-Windows-Setup.exe: open it and click Download and install.
- PortalAI-Academic-Mac-Setup.zip: extract and open PortalAI Academic Installer.app.
- PortalAI-Academic-Linux-Setup.sh: run bash PortalAI-Academic-Linux-Setup.sh.

Each student downloads only the launcher for their operating system. It fetches
that platform's parts from GitHub, verifies hashes, reconstructs and extracts
the original installer, then starts the Academic installation. No manual part
downloads or reassembly are required. The repository README includes the three
download links; they become usable after the complete commit is published.

The copies of the three launchers next to this guide are for convenience.
The GitHub commit needs the ENTIRE folder above, including all package parts.

LIMITATIONS
Full original packages were tested from preloaded verified parts; network
download/failure tests used small fixtures. Large local HTTP transfers also
experienced connection resets on this host. A complete download from the
actual public GitHub package URLs cannot be tested until the files are committed.

Avast autosandbox intercepted direct Windows test executables. The Windows
download/reconstruction code and GUI were therefore also tested through their
managed .NET entry point in PowerShell. The separate Windows child-launch test
received Access denied and remains unverified; it is not counted as a pass.
No antivirus settings, exclusions, or security policies were changed.

Mac Finder/Terminal opening and physical Mac/Linux installations have not been
run. Git Bash testing is not a substitute for native-platform acceptance. These
launchers are unsigned; recipient OS/security approval may be needed.

No actual application installation was started during launcher validation.
The current PortalAI installation and original Academic archives were unchanged.
