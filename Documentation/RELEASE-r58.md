# Windows r58 — lightweight portable capabilities

Adds projects/shared instructions, reviewed text skill imports, preregistered-client MCP OAuth and granted resources/prompts, a native workflow step editor, workflow API routes, tap-to-interrupt voice, optional headphone interruption/Piper sentence streaming, idle knowledge refresh, sequential effort-profile comparisons, offline Markdown/Mermaid/React artifacts, and Windows accessibility targeting/drag.

Installed application growth: **6,043,167 bytes per independent Full SSD** (about 6.04 MB). No new model weights, Python/Node runtime or resident service. Existing SSD reserves apply. Most growth is pinned browser renderers loaded only for preview. User content, browser working memory, installer archives and recovery/test copies are separate. The approved Qwen voice, pitch and playback padding are retained.

Intentional limits: Qwen is not streamed; spoken interruption needs headphones and has no echo cancellation; comparisons run sequentially and respect manual model overrides; skills are text-only; OAuth requires a compatible registered public client; artifact previews open on demand in isolated browser windows. API tools run through reviewed workflows; ordinary API chat remains text-only. These are useful bounded implementations, not full feature parity with every referenced distribution.

Validation: 600 application tests per D/E installation and exact extracted edition (598 passed, 2 skipped); 45 installer tests per edition; seven embedded resources, Academic compiled launcher, real offline Chromium previews including React interaction/isolation, native GUI inspection, real owned audio-player interruption/restart, and real Windows accessibility/password exclusion. OAuth uses a synthetic loopback provider. Physical-microphone barge-in, real-provider sign-in, live multi-model comparison and a complete fresh recipient installation were not tested. Drag cleanup/stale targets use boundary tests.

D: and E: application files and installer kits are independently updated. The deprecated C: installation was excluded. Windows is r58; Linux/Mac remain r51. **Exit and reopen PortalAI normally** to load the update.
