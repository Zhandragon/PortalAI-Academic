PortalAI 2026.10.27-Desktop-r48 — Academic Mac

Unified public application and companion source from the reviewed D/E versions.
Includes native-controls registration, web-search evidence, tracked refresh,
authenticated account import/setup, executable recovery, Mac lifecycle/input,
and version-aware upgrades. Platform runtimes and Academic policies are retained.

Keep this complete extracted package together. Run the installer for your OS.
Windows: open PortalAI-Install.exe; choose a new folder or Update existing.
Linux: run ./install.sh [application-folder] [--upgrade].
Mac: run ./install-macos.sh [application-folder] [--upgrade].
For an existing folder the Unix default is a read-only version check.
Exit PortalAI normally and wait for account sealing before updating.
Known older stamped/verified legacy releases are supported. Unknown versions,
downgrades, other editions and uncertain account states stop for review.
Updates preserve existing accounts, preferences and optional assets, retain
verified recovery copies and block startup after an interrupted transaction.
Existing companion installations require the separate companion update;
application upgrades do not overwrite saved companion connections.

Hardware selection remains automatic within the runtimes/models installed:
CUDA/Vulkan/CPU on Windows/Linux; Metal/CPU on macOS. Available RAM/VRAM,
explicit model choices and storage reserves still limit admission. Detection
does not make every media capability work on every backend or architecture.
No host Python or Node installation is required. Initial setup needs internet
for additional runtimes and model downloads; this is not an offline installer.
The installed selected components remain under the portable application root.
Web search and remote integrations need their respective network/services.

Mac requirements: Intel x86_64 or Apple Silicon arm64; Apple developer tools,
the Metal shader compiler and CMake are required by this build-on-install path.
These are not guaranteed on a stock Mac. The installer downloads pinned CMake
inside PortalAI and offers Apple-managed Command Line Tools/Xcode/Metal setup.
Apple setup requires confirmation; it never silently installs system tools.
Prebuilt pinned backends are still needed to meet a compiler-free setup goal.
The companion requires macOS 14+ and user-granted screen/accessibility access.
Choose a writable filesystem that preserves executable permissions.

Verification: see manifest/release.json and package checksums. Packaged source
and disposable Windows tests are recorded separately; physical Linux/Mac and
clean online recipient installs are not established by this Windows build.
No owner account, keys, saved connection, output or private configuration is
included. Deprecated means superseded for PortalAI's self-contained goals,
not old according to a third-party package distributor. Nothing is removed.
