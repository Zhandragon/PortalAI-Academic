PortalAI Windows r80 - media planning, shutdown and desktop acceptance
Version: 2026.11.21-Desktop-r80

MEDIA GENERATION
Simple familiar scenes can generate directly. Specialized or uncertain subjects
must inspect at least three reference images and compare two read source pages.
The model assesses unfamiliarity as well as keyword hints. Complex scenes plan
sequential edits, inspect outputs and preserve the previous result. A successful
file save is not visual verification. Scientific accuracy still requires review;
no live CRISPR image-quality benchmark was completed for this release.

STOP AND EXIT
Idle Stop now cancels resources. Stop-all continues other cleanup when one step
fails, reports failures and stops verified owned scripts outside the former name
catalog. Detached descendants retain process creation identity checks. Stop and
normal X/Exit preserve account sealing and mission/schedule cancellation fences.
Independent suite programs such as Projection and user apps such as Chrome or
Slippi retain their separate lifecycle; stopping the assistant revokes its input
grants, rather than closing those independently opened programs.

COMPUTER AND BROWSER USE
Desktop actions use exact observed control names plus IDs and fresh tokens.
Paged accessible state, desktop double-click, delivered-input receipts and
bounded continuation improve multi-step tasks. Nice can navigate its own visible
pages and open Projection through Controls > Utilities without arbitrary GUI
method access. Browser Space key handling now works with the pinned harness.
Existing explicit per-login window grants and account guards remain required.

VALIDATION AND LIMITS
Live local Qwen 27B navigated Chrome through Twitter/X to Gavin Newsom's profile,
launched Slippi from its desktop icon, and navigated Windows folders. Qwen 4B
opened Projection using the real PortalAI button in a disposable GUI/account.
The smaller model was inconsistent on general desktop tasks; repeated trials
are not a reliability benchmark. Some successful navigation runs still ended
with verification errors; full transcripts remain private on the test machine.
Headless browser tests covered forms, multiple tabs, switching, checkbox keyboard
input, history, stale observations, private URLs, guest restrictions and cleanup.
Owned-script shutdown preserved an unrelated process. Normal disposable GUI X
completed verified account sealing. Automated regression results are recorded
in RELEASE-r80.md. A native fixture passed real mouse/key input, screenshot, resizing, stale-token
rejection and revocation after a scoped window-activation fallback was added.
Input-queue attachments always detach before input, including cancellation.
Common keyboard aliases are normalized before input. Windows can still refuse
activation; the assistant reports refusal rather than targeting another window.

PACKAGING
Cumulative Windows update includes r79 computer-use, Stop, resizing and validated
voice streaming changes. Full, Academic and 72-hour Trial policies are preserved.
Linux/macOS installers remain experimental r75 and were not natively retested.
No clean recipient installation or live physical Aoostar/HA deployment is claimed.
Use normal Exit and the checked updater; preserve accounts, models and settings.

Regression evidence: 160 focused checks passed, 64 web checks passed,
88 shutdown/profile checks ran (87 passed, one platform skip), and a final
41-check boundary suite passed after the focus/key-alias corrections.
These overlapping suites are reported separately, not summed as unique tests.
