PortalAI Windows taskbar icon — October 23, 2026

The existing PortableAI.ico already contains nine sizes from 16 through 256
pixels, including the detailed 256px artwork. The native launcher embeds the
same icon. No new artwork, image library, runtime or launcher rebuild is needed.

The bundled Tk 8.6 iconbitmap(default=...) path was verified to supply only a
32px large / 16px small window-class icon pair, with no explicit window icon.
Those small images are susceptible to enlargement by the Windows shell.

ControlCenter/window_icons.py now gives the actual native Tk wrapper explicit
256px large and 64px small icons through WM_SETICON, loaded directly from the
existing multiresolution ICO. Both are large enough for ordinary scaled
taskbar/Alt+Tab rendering. Native WM_GETICON/GetIconInfo tests confirm those
pixel dimensions rather than assuming that the source file is being used.

The helper attaches on coalesced Map/Configure events, handles wrapper
recreation, reuses the two owned handles, and releases only its own handles
when the root is destroyed. Ordinary resize does not reload images or resend
unchanged handles. The existing Tk icon remains a fallback if loading fails.
Non-Windows hosts retain their existing path. No WndProc subclass, new global
DPI policy, taskbar grouping identity, tray change or minimize change is added.
