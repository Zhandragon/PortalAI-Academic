PORTALAI PROFILE CONNECTIONS - October 24, 2026

The general connection runtime supports encrypted, profile-bound service
connections. It does not include the originating machine's one-off migration
menu, credential-source importers, mission objective or setup request. Users
create and configure their own missions and schedules through the normal UI.
Existing connection bundles remain compatible; no migration is performed.

Connections use an AES-256-GCM bundle under private Data/Accounts. An HMAC-SHA256
key derived from the authenticated profile key and user ID stays in controller
memory. Owned mission workers receive only the account-derived key through a
bounded anonymous startup pipe, never argv, environment, logs or files. The
profile key is not exported. Lock clears the key and shutdown joins workers
before sealing. Account switches, wrong keys and tampering fail closed. Legacy
manually unlocked vaults remain supported. Full host access is not OS isolation.

The account profiles operation exposes supported operations and parameters,
never secrets. Mail, wallet, GitHub and Moltbook adapters retain their explicit
connection permissions. GitHub binds both account login and numeric identity;
repository writes are limited to the configured account, creation is private,
and pull requests are drafts. API credentials go only to fixed TLS hosts with
redirects disabled. Results are bounded, untrusted and redacted.

External writes retain durable pending/confirmed journals. Uncertain effects
are never automatically replayed. Autonomous recovery cannot clear an uncertain
mail send, wallet transfer, GitHub write or Moltbook post/verification. Rate limits
persist cooldowns. Credentials must not be placed in model prompts or memory.

Tests use synthetic connections and disposable authenticated accounts. They
exercise encryption, account/epoch isolation, worker startup pipes, redaction,
fixed hosts and no-replay behavior without contacting live services. No owner
account, credential, setup request or mission database belongs in a distribution.
