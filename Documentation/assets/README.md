The screenshots were captured on October 20, 2026 from an isolated copy of the Academic payload. A capture harness runs the original full Control Center UI construction while replacing account access, runtime processes, background jobs and network services with inert preview substitutes. It preserves the application's widget construction, custom title bar, borders, navigation and compact-mode implementation. The welcome capture shows the complete emblem at a window size that accommodates it.

The windows were recaptured in Light mode against a solid black backdrop to prevent nearby desktop content from showing through their rounded corners and outer edges. Each window retains enough height to show the complete welcome emblem and keep page branding clear of the controls. Only the application window's screenshot is used in the gallery.

The settings panels use an in-memory sample inventory, with models marked as not installed. The chat text is an illustrative classroom example supplied for the screenshot; it was not generated by a running model. No personal profiles, chat history or credentials were loaded, and no model workers or application installation were started. The active PortalAI installation and the published installer packages were not modified.

These are screenshots of real widgets, not generated interface mockups. The original screenshots and transparent branding images are preserved without visual edits. Platform styling and available components may differ on recipient systems.

The additional Runtime, Packages, context-help and tray captures retain the same Light palette, decorative borders and black backdrop. The capture harness enables the real Windows notification-icon thread and a limited event pump while leaving model workers, account access and networking disabled. A capture-only F8 shortcut invokes the unmodified notification-menu function at a clear position, so the published image contains no unrelated tray icons. F8 is not advertised as a product shortcut. The tray menu image is a direct bounded capture of that menu, not a composite. Runtime chart values are illustrative, not measured performance; package status is not a claim that the full installation is missing those dependencies.

The gallery captures predate the Academic r2 package-status correction. Current installers display EXCLUDED for intentionally omitted alternate models rather than the older preview's CHECKING rows.
