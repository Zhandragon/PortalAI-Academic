# Supporting PortalAI

PortalAI was initially developed over a month by one person, who is now continuing to improve its features and capabilities. If you find use from this program and would like to support its continued development, please consider donating, either via the Github Sponsors program or directly here via PayPal or crypto.

[Sponsor Zhandragon on GitHub](https://github.com/sponsors/Zhandragon)

Open **Donation**, immediately after **Help**, in PortalAI Full or Academic. The page includes the original PortalAI logo and wordmark, PayPal/Ethereum/Polygon/Bitcoin QR codes, and a GitHub Sponsors button. Clicking a QR code, its destination text or its Copy button copies the exact URL/address to the local clipboard and displays confirmation. QR clicks do not initiate a transfer. Ethereum and Polygon share the supplied address and have separate network labels.

The Welcome page also has a Sponsor on GitHub button beneath its introduction. The repository's Sponsor button and the welcome README link open the same maintainer profile.

The layout follows the current light/dark palette and reflows from four columns to two or one on narrower windows; the page remains scrollable. The original QR image bytes are retained with hashes in `ControlCenter/DonationAssets/PROVENANCE.json`.

Validation: five real Tk donation tests cover exact clipboard strings, explicit sponsor navigation, palette changes and responsive layout. The actual Windows launcher was checked with a disposable account, including Donation/Welcome/Help navigation, six Controls buttons and verified account sealing. All four QR destinations decoded correctly from both light and dark launcher screenshots. No donation was sent. Physical Linux/macOS UI acceptance remains pending.

Normal PortalAI exit and relaunch loads the UI update. Existing owner accounts, models, credentials and connections are outside this update.
