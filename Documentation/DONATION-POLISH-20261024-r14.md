# Donation typography and layout — r14

The Donate title-bar link now uses approved option B: the same display font as Support PortalAI at the main tab titles' default size, with no underline and a lower vertical position.

Donation cards have rounded gold borders and white QR-image corners in light and dark modes. Tighter spacing fits the entire page, including the thank-you message, at the default 1260 x 820 window size. Smaller windows retain scrolling. QR canvas sizes, QR module pixels, artwork and destinations are unchanged.

Full and Academic packages for Windows, Linux and macOS include the update. Academic model policy, account-lock/exit guards and the exclusion of the temporary Aoostar importer are preserved.

Windows GUI and package validation are recorded with this release. Physical Linux/macOS/Aoostar acceptance and full fresh model downloads were not performed for this UI change.

Detailed evidence: [validation report](DONATION-POLISH-VALIDATION-20261024-r14.json).
