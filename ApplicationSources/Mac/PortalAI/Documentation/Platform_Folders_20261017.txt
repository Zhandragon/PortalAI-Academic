PORTALAI PLATFORM FOLDERS AND STARTUP — 2026-10-17

The product uses a separate native installer and runtime for each OS:

  Windows: PortalAI Windows\PortalAI.exe; SSD shortcut: Start PortalAI Windows.cmd
  Linux:   PortalAI Linux\PortalAI.sh; SSD shortcut: Start PortalAI Linux.sh
  macOS:   PortalAI Mac\PortalAI.app; SSD shortcut: Start PortalAI Mac.command

The three launchers are not interchangeable. The Windows installer creates a
PortalAI Windows folder at the chosen SSD root; Linux and Mac installers use
PortalAI Linux and PortalAI Mac defaults. The Mac installer should be installed
on the Mac's APFS volume or local Applications folder, not run from this
Windows NTFS SSD. Linux and Mac installs may be directed to a native filesystem
on their own host. Models and private accounts are not copied between OS builds.

The old drive-level PortalAI.exe was not rebuilt because no Windows C compiler
is installed here. It may not locate the new folder name. Use the new Windows
command launcher. The drive-level PortalAI.sh resolves the Linux-named folder.
Each launcher refuses ambiguous or missing installs.
